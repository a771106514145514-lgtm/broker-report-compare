# 券商報告比對

把同一檔股票的多份券商 PDF 研究報告丟進去，一次整理出：

1. **各家的目標價**
2. **各家對每一年的 EPS 預估**（預設 2026、2027，可改）
3. **大家都重複提到的內容**
4. **每一家獨有的內容**

再加一頁「重點整理」：共識數字（中位數、區間、隱含成長與本益比、評等分布）、
誰的預估站在極端、大家都在談什麼題材、只有某一家講的觀點。

## 特點

- **不用安裝**：一個 HTML 檔，開網址就能用，手機也可以。
- **不上傳**：PDF 在你自己的瀏覽器裡解析，不會傳到任何伺服器。開啟後全程不連網路。
- **掃描檔也讀得到**：整頁都是圖的 PDF 會就地辨識（內建繁中辨識引擎，一樣不連網路）。
- **每個數字都可以查證**：點下去看得到是從第幾頁、哪一句抓出來的，抓錯可以當場改，
  表格、中位數與匯出檔案都會跟著更新。

## 怎麼用

1. 開啟網址
2. 選擇（或拖曳）要比對的 PDF —— 會先列出清單
3. 按「開始比對」

右上角可以複製重點（貼 LINE／Email）、複製表格（貼 Excel）、匯出 CSV 或 Markdown 報告。

## 它是怎麼抓的

同一個數字在報告裡通常出現好幾次——財務預測表一次、內文敘述一次、
「本次／前次」比較表再一次。程式把每條路找到的候選值都留著，
再依來源可信度與互相佐證的程度投票決定答案，而不是靠單一條正則。

券商報告的排版差異極大，程式只能盡量抓對。
**做投資決定前，請務必自己核對關鍵數字。**

## 授權

本工具的程式碼可自由使用。內含的第三方元件見 [THIRD-PARTY.md](THIRD-PARTY.md)。

# 附近好吃好買

出門在外用的另一支小工具（[travel.html](travel.html)），跟上面的報告比對無關。

打開網頁，按一下「用我目前的位置」，它就把你周圍可以吃、可以逛的地方排成一頁圖卡：
**看圖就知道賣什麼**——拉麵、壽司、火鍋、咖啡、麵包各有各的圖，不用先讀完店名。
點一家就跳出詳細，再按一下就在地圖上畫出你走過去的路線。

## 特點

- **用看的選**：圖卡依「賣什麼」配圖與配色，掃過去就挑得出來。
- **地圖上直接看**：地圖標出你的位置與每家店（圖釘上也是同一個料理圖示），
  選一家就畫出**實際的步行路線**，告訴你多遠、大概走幾分鐘。算不出路線時會退回直線，
  並明講那是直線距離。
- **不用安裝、不用註冊**：一樣是一個 HTML 檔，手機開網址就能用。
- **位置不外流**：座標只拿去 OpenStreetMap 問「這個座標附近有什麼」，這個工具沒有伺服器收你的位置。
- **不給定位也能用**：直接輸入地點（例如「京都車站」），出發前先查也行。
- **收訊差的時候有救**：上次查過的結果會留在瀏覽器裡，人還在同一個地方而連不上時，先給你看那一份。
- **挑不出來就按「隨便選一家」**：從最近的幾家裡抽一家給你。

三種看法可以切換：**圖卡**（用看的挑）、**清單**（資訊最全）、**地圖**（看方位與路線）。
可以篩「吃的／買的」與細項（正餐、小吃速食、咖啡甜點、超商超市、百貨商場、藥妝、書店…），
也可以只看現在營業中的，或直接打店名、料理搜尋。

## 注意

- 定位需要用 https 開啟（GitHub Pages 之類的靜態空間就可以）；直接按兩下打開檔案的話，
  瀏覽器通常不給位置，改用搜尋地點即可。
- **圖卡上的圖是依店家類型自動配的示意圖，不是那家店的實際照片。**
  OpenStreetMap 沒有店家的餐點照片，也沒有免費又不用金鑰的來源；
  與其拿別處的美食圖片充數，不如老實用示意圖。
  少數店家自己在 OSM 上登記了照片（`image` 或 `wikimedia_commons` 欄位），那種才會顯示真實照片。
- 店家資料來自 OpenStreetMap 社群，**沒登記名稱的店不會出現**，營業時間也可能過時或沒人填。
  營業時間的寫法千奇百怪，程式看不懂的就只顯示原文、不猜它開不開。出發前建議再確認一次。
